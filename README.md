# 🌴 TripMate

TripMate is a travel and accommodation application designed to help users discover stays, organize trips, manage their budget, and keep track of reservations in one convenient platform.

The application was developed using Ionic and Angular with a responsive design for both web and mobile devices.

## ✨ Features

- 🏠 Browse available stays
- 🔍 Search and filter accommodations
- ❤️ Save stays to a wishlist
- 📅 Create and manage itineraries
- 💰 Budget tracker
- 📋 Manage reservations
- 🏡 Become a Host
- 👤 User profile and authentication
- 💳 Booking and payment flow
- 📱 Responsive web and Android design

## 🛠️ Technologies Used

- Ionic Framework
- Angular
- TypeScript
- HTML
- SCSS
- Capacitor
- Supabase
- Android Studio
- Git & GitHub

## 📱 Mobile Application

TripMate uses Capacitor to convert the Ionic Angular application into an Android application.
